这两组设置管的是不同阶段：
· 首次提醒不需要任何等待——本轮读到的数据一旦越过阈值就立刻提醒。
· 上面的选项管的是故障已经在报了以后：选「每次巡检都提醒」则每轮都再报一次， 同一台设备也照报；选「只在状态变化时提醒」则只在故障新出现或恢复正常时报。

账号管理

账号来自工具目录下的 accounts.csv，点击「编辑账号表格」用默认程序打开。本工具理论支持且只支持由有人云平台分发的账号。

从上往下按顺序匹配变量名（包含即命中：「出水温度」也命中「出水温度1」）。 数据监控、巡站截图、历史数据三处都按这张表排，顺序定死就不会再来回跳。 带「修正 / 原值 / 设定 / 系数 / 补偿 / 偏置」的工程参数不参与置顶；取消勾选＝这条不生效。 改动即时保存，不用点上方的「保存设置」。

还没有置顶站点。点下面「添加站点…」，或在设备列表里右键 →「置顶该站」。

置顶的站固定排在巡站截图、数据监控、历史数据三个列表最前面，并成为自动选中的第一台。 这里从上到下的顺序就是置顶区里的先后（↑ ↓ 调整）；点 ✕ 取消置顶后它会回到原来的位置。 也可以在设备列表里直接右键置顶，两处是同一份数据。改动即时生效。
